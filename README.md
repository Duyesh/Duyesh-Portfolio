## Overview

This portfolio was designed and developed from scratch using modern frontend technologies with a strong focus on:

* Cinematic visual design
* Smooth interactions and animations
* Responsive layouts across devices
* Professional project presentation
* Modern UI/UX principles

The goal was to create a portfolio that feels less like a traditional website and more like a carefully crafted digital experience.

## Installation

Clone the repository:

```bash
git clone https://github.com/Duyesh/Duyesh-Portfolio.git
```

Navigate into the project folder:

```bash
cd your-repository
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
